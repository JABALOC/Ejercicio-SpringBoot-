# Ejercicio-SpringBoot

Proyecto de práctica con Spring Boot para experimentar con la creación de APIs y gestión de datos en un backend sencillo. Permite realizar operaciones básicas y probar consultas.

## 📂 Contenido del proyecto

- Operaciones CRUD básicas
- Gestión de datos en el backend
- Ejemplos de consultas y pruebas

## 📚 Mejoras futuras

- Integrar un frontend para consumo de APIs
- Añadir validaciones y seguridad
- Optimizar la estructura de datos y consultas
